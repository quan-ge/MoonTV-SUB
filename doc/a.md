# 订阅详情文档

## 三个版本的区别

| 版本 | ID       | R18源 | 影视源 | 源数量 | 上次更新 |
| ---- | -------- | ----- | ------ | ------ | -------- |
| 通用 | sub      | ❌     | ✅      | 36     | 26.8.11  |
| R18  | sub_r18  | ✅     | ❌      | 23     | 26.8.11  |
| 性能 | sub_lite | ⭕     | ⭕      | 50     | 26.8.13  |
| 完整 | sub-all  | ✅     | ✅      | 71     | 26.8.13  |

✅：包含 / ❌：不包含

⭕：为了保证性能，只包含一部分

## 备注

 - 如果订阅源有更新，几乎所有版本的软件 都不会同步订阅中被删除的源，
   请在`管理员设置`中手动删除
 - APP不支持订阅时可参照下方方法手动导入配置
 - **使用完整版时，可能会因为源过多，导致速度变慢 或卡死，甚至导致应用部署失败**

## 旧版使用方法

 - 访问订阅的URL，将订阅复制下来，例如：`https://quan-ge.github.io/quan-ge/sub/moontv_sub.txt`
 - 前往[Base58转换工具](https://www.udtool.com/toolbox/base58-encoder-decoder.html)
 - 输入后点击`点击解码`，进行Base58解码，将订阅转为配置文件
 - 部分项目需要对配置文件稍作修改
 - 手动导入配置文件
